# 首版实现与验证记录

日期：2026-10-27。新房默认内容版本：`demo-v3`；保留 `demo-v2` 供旧存档继续加载。当前按用户决定使用局域网 HTTP 直连，Cloudflare 隧道已关闭。局域网地址的双人协议测试通过；真实两台玩家设备的网络互通和完整试玩待验收。

## 实现范围

新版已实现大厅三个区域 meta、西区 final，以及三区 meta 首次同时正确后永久开放西区。开放时间和答题结果在同一事务内保存，广播、重连、服务重启与备份恢复均保留。北区两间题室分别放置 N1-A / N1-B，直接复用普通题的独立答案和通过状态；没有合并判定或角色专属答题权限。东区左右成对布置题位，南区采用不可通行的静态水池和步道。正式镜像题、水机制与小游戏尚未实现。设计见 [PLAN.md](../PLAN.md) 第 1.1–1.5 节与 M7。

## 仍待验收

1. 两台玩家电脑与主机在同一可互通局域网，从加入到 final 的完整流程及 30 分钟运行。不能以同机双会话代替实际设备测试。
2. 若以后改回长期公网托管，再验证容器镜像、DNS、TLS 和反向代理；这些不再是当前局域网试玩的上线条件。
3. 浏览器层面的离线关闭、确认消息丢失、休眠恢复、输入法、长题面和图片布局；协议层已有相关处理，但不能把代码存在当成所有浏览器时序都已验收。
4. 正式图片的受权素材路由、视觉素材替换，以及实际部署备份复制到开发机。当前占位题面使用文本；正式剧本、关卡与贴图不阻塞本地试玩。

数据库模式为一个游戏进程服务多个存档，首次只面向一房两人。应用进程内维护实时控制连接，不支持直接横向扩展为多个应用实例；正式扩容需要额外的跨进程协调。

备份实现使用一致性事务导出的应用 JSON，而非依赖本机 `pg_dump`。恢复拒绝覆盖现存数据，检查文件校验和、原 APP_SECRET 与内容版本哈希，生成新 saveEpoch。数据库备份以外，仍需保存原密钥及对应内容目录。
